# 中1英語 期末試験対策 演習アプリ

中1英語の期末試験範囲（Lesson 7・Lesson 8の文法およびREAD）に特化したWeb演習アプリです。

## 特長
- **単元別演習**: Lesson 7 / Lesson 8 の文法・読解問題、間違えた問題の5モード
- **間違えた問題の自動ストック**: 間違えた問題は `localStorage` に自動保存され、復習可能
- **スマホ最適化**: 4択・空所補充形式でスムーズに回答可能

## 使い方
`index.html` をブラウザで開くか、GitHub Pages などのホスティングサービスにアップロードしてご利用ください。
