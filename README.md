# 中1英語 期末試験対策＆動詞の過去形特訓 演習アプリ

中1英語の期末試験範囲（Lesson 7・8）および添付の「動詞の過去形（不規則動詞・規則動詞）」に特化したWeb演習アプリです。

## 新設モード
- **★ 動詞の過去形特訓（全45問）**:
  - 画像に掲載されている**不規則動詞全30語**（begin ➔ began, bring ➔ brought, come ➔ came ...等）
  - 画像掲載の**規則動詞4パターン全15語**（edをつける / dだけつける / yをiに変えてed / 子音字を重ねてed）
  - 原形から過去形をテキスト入力で回答する形式で、ランダムに出題されます。

## その他のモード
- Lesson 7 文法 / Lesson 7 READ
- Lesson 8 文法 / Lesson 8 READ
- 🔥 全単元コンプリート模試
- ⑤ 間違えた問題（自動ストック）
