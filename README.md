# 中1英語 期末試験対策＆動詞の過去形特訓 演習アプリ

中1英語の期末試験範囲（Lesson 7・8）および添付の「動詞の過去形（不規則動詞・規則動詞）」に特化したWeb演習アプリです。

## 今回の追加・変更点
- **Lesson 7 文法**: 進行形の否定文・疑問文演習を**10問追加**（全26問）
  - うち5問は「全文英作文入力」形式（例：`Ken is not playing tennis now.`）
- **Lesson 8 文法**: 過去形の否定文・疑問文演習を**10問追加**（全28問）
  - うち5問は「全文英作文入力」形式（例：`Did they watch TV last night?`）
- **判定ロジックの改善**: 全文入力時のピリオド・クエスチョンマークの有無や大文字小文字、短縮形（`isn't` / `is not` / `didn't` / `did not`）の自動表記揺れ吸収機能を実装しました。

## モード一覧・問題数
- **★ 動詞の過去形特訓（全45問）**
- **① Lesson 7 文法（全26問）**
- **② Lesson 7 READ（全12問）**
- **③ Lesson 8 文法（全28問）**
- **④ Lesson 8 READ（全12問）**
- **🔥 全単元コンプリート模試（全123問）**
- **⑤ 間違えた問題（自動ストック）**
