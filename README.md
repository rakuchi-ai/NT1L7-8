# 中1英語 期末試験対策＆動詞の過去形特訓 演習アプリ

中1英語の期末試験範囲（Lesson 7・8）および添付の「動詞の過去形（不規則動詞・規則動詞）」に特化したWeb演習アプリです。

## 完全動作修正版
- **画面遷移の不具合を修正**: `showScreen` 関数のセレクタのタイポを修復し、すべてのメニューからスムーズに問題画面へ移動できるよう対応しました。
- **L7 / L8 文法（全54問）**: 否定文・疑問文の演習を強化（各10問追加、うち各5問は全文英作文入力形式）。
- **判定補助**: 文末のピリオド・クエスチョンマークや大文字小文字、短縮形（`isn't` / `is not` / `didn't` / `did not`）の自動正規化判定に対応。
