# 中1英語 期末試験対策 全問題演習アプリ

中1英語の期末試験範囲（Lesson 7およびLesson 8の文法・読解全範囲）をカバーした問題集アプリです。全58問の大ボリュームで定期テスト対策が完結します。

## 単元別問題数
- **① Lesson 7 文法（16問）**: 現在進行形、-ing形作り方、進行形不可の動詞、疑問文・否定文
- **② Lesson 7 READ（12問）**: Hospital Clowns、前置詞（about, between, from, around）、本文内容理解
- **③ Lesson 8 文法（18問）**: 過去形（規則・不規則変化）、時間・場所・疑問詞の疑問文・否定文
- **④ Lesson 8 READ（12問）**: Greetings from Alaska、前置詞・熟語（one of, come close to, take pictures of）、本文内容理解
- **🔥 全単元コンプリート模試（全58問）**: 全問題をランダムに一括総復習する本格模試モード

## 主な機能
1. **問題のシャッフル＆選択肢ランダム化**: 正解の番号（1〜4）および出題順が毎回変わるため丸暗記を防ぎます。
2. **キーボード記述入力**: 空所補充や動詞の活用変形問題は、手入力でしっかりとスペルチェックできます。
3. **誤答の自動復習機能**: 間違えた問題のみを保存・再選出する自動ストック機能。

## 使い方
`index.html` をGitHub Pagesに更新・配信するか、ローカル環境で直接開いてご利用いただけます。
