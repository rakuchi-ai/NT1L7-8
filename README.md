# 中1英語 期末試験対策 演習アプリ

中1英語の期末試験範囲（Lesson 7・Lesson 8の文法およびREAD）に特化したWeb演習アプリです。

## 主な機能・改修点
- **選択肢のランダムシャッフル**: 4択問題の正解の位置（1〜4番）が毎回ランダムにばらつくように自動処理されています。
- **キーボードテキスト入力対応**: 空所補充問題や進行形・過去形への書き換え問題では、4択ではなくキーボードから直接英単語を入力して解答する仕様に変更しました。
- **即時判定＆詳しい解説**: 解答送信・選択後すぐに正解判定と解説が表示されます。
- **間違えた問題の自動ストック**: 誤答した問題は `localStorage` に自動保存され、復習モードで集中的に解き直せます。

## 使い方
`index.html` をGitHub Pagesなどのホスティングサービスに更新（Commit & Push）するか、ローカルのブラウザで直接開いてご利用ください。
