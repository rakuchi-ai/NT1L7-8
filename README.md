# 中1英語 期末試験対策 演習アプリ

中1英語の期末試験範囲（Lesson 7・Lesson 8の文法およびREAD）に特化したWeb演習アプリです。

## 特長
- **即時採点＆解説機能付き**: 回答後、すぐに正解・不正解が分かり、詳しい解説が表示されます。
- **単元別演習**: Lesson 7 / Lesson 8 の文法・読解問題、間違えた問題の合計5つのモード。
- **間違えた問題の自動ストック**: 間違えた問題はブラウザ（`localStorage`）に自動保存され、復習モードで集中的に解き直せます。
- **スマホ最適化**: 4択・空所補充形式でサクサク学習が可能です。

## 使い方
`index.html` をブラウザで直接開くか、GitHub Pages などのホスティングサービスにアップロードしてご利用ください。
